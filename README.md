🚑 ResQ Route – Intelligent Emergency Vehicle Route Optimization System

Smart Routing. Faster Response. Better Decisions.

🌟 Project Overview

ResQ Route is an intelligent, web-based emergency vehicle route planning and optimization system designed to identify efficient routes from an emergency location to the most suitable hospitals.

The system combines Graph Algorithms, Advanced Data Structures, and Interactive Simulation to demonstrate how intelligent route planning can support faster emergency response.

Unlike basic shortest-path applications, ResQ Route introduces simulated traffic conditions, road blockages, hospital specialization, and emergency prioritization to create a more realistic emergency routing environment.

Its primary goal is to demonstrate how computational intelligence can help make emergency transportation more efficient, adaptive, and decision-oriented.

🎯 Key Features

- 🚦 Dijkstra's Algorithm: Calculates the shortest available route based on road distances and weights.
- 🧠 A Search Algorithm:* Uses heuristic-based search to identify an optimized route.
- 🏥 Smart Hospital Selection: Uses an AVL Tree to efficiently search and organize hospitals based on specialties.
- ⚡ Emergency Priority Management: Implements a Priority Queue to demonstrate priority-based emergency handling.
- 🚗 Dynamic Traffic Simulation: Simulates changing traffic conditions that influence route selection.
- 🚧 Road Blockage Simulation: Demonstrates how blocked roads affect route availability and optimization.
- 🚑 Ambulance Route Animation: Visually represents ambulance movement along the selected route.
- 📍 Interactive City Map: Provides a visual representation of locations, roads, hospitals, and routes.
- 📊 Route Comparison: Compares alternative routes to demonstrate differences in distance and estimated travel cost.
- 🔄 Adaptive Route Recalculation: Demonstrates route updates when simulated road conditions change.

🧠 Core Algorithms & Data Structures

1. Dijkstra's Algorithm

Finds the shortest path between the emergency location and destination by calculating the minimum cumulative distance across the road network.

2. A* Search Algorithm

Uses the actual path cost and a heuristic estimate to guide the search toward the destination efficiently.

3. AVL Tree

Maintains a balanced search tree to support efficient hospital specialty searching.

4. Priority Queue

Organizes emergency cases based on assigned priority levels, demonstrating how critical cases can receive higher attention.

⚙️ System Workflow

Emergency Input → Location Selection → Hospital Identification → Route Calculation → Traffic & Blockage Analysis → Route Comparison → Ambulance Simulation

The system demonstrates the complete route-planning process through an interactive interface.

🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.
4. Select the starting location and patient location.
5. Choose the required route-finding algorithm.
6. Click Find Optimized Routes.
7. Explore route comparisons and hospital information.
8. Use the simulation controls to test traffic changes and road blockages.
9. Observe the ambulance route animation and updated route visualization.

💡 Project Innovation

ResQ Route goes beyond demonstrating a conventional shortest-path algorithm.

It combines multiple concepts from Data Structures and Algorithms into one interactive application:

- Algorithm comparison through Dijkstra and A*.
- Hospital discovery using an AVL Tree.
- Emergency prioritization using a Priority Queue.
- Simulated real-world challenges such as traffic and road blockages.
- Visual route exploration through ambulance animation.

This integration demonstrates how different computing concepts can work together to address a meaningful real-world problem.
